## 🌟 Overview

Step into a fully interactive 3D developer workspace built in WebGL. Navigate around the room, explore projects, test live terminal commands, play arcade games, draw on the whiteboard, and solve the Rubik's cube.

### 🖥️ Dual Interactive Monitor Workstation
- **Left Monitor (Roshan OS):** A custom simulated desktop operating system featuring:
  - **About Me:** Biography, background, and stats.
  - **Skills Arsenal:** Technical stack across AI, LLMs, Computer Vision, and Web Development.
  - **Interactive Terminal:** Run custom commands directly within the 3D room.
  - **Embedded Resume Viewer:** Read the full PDF resume directly on the screen or open/download it in a click.
- **Right Monitor (Projects Matrix):** Filterable portfolio dashboard categorizing projects:
  - 🤖 **AI / LLMs:** Autonomous AI agents, trauma ER dashboards, and fintech SaaS platforms.
  - 👁️ **Computer Vision:** Real-time OpenCV & MediaPipe hand tracking, background removal, and invisibility cloak.
  - 💻 **Desktop Runtimes:** Voice-controlled local macOS assistants and native system utilities.
  - 🛡️ **Cybersecurity:** Network stress test tools and security analyzers.
  - 🌐 **Web Applications:** Responsive dashboards and full-stack tools.

### 🕹️ Retro Arcade Machine
- Fully playable 2D Space Shooter mini-game rendered directly on the arcade screen with dynamic keyboard controls, enemy waves, audio effects, and live scoring.

### 📝 Interactive Whiteboard
- Real-time marker whiteboard with selectable color markers (Black, Red, Green, Blue, Eraser) for sketching and notes.

### 🎲 3D Rubik's Cube
- Interactive 3D Rubik's Cube on the side cabinet with custom touch and drag rotation controls.

### 🎬 Photorealistic Baked Environment
- High-fidelity textures with baked shadows, ambient occlusion, custom framed wall art, and a movie clapperboard dedicated to **Roshanpreet Singh Dhiman**.

## 🛠️ Tech Stack

- **3D Graphics & Rendering:** [Three.js](https://threejs.org/), WebGL, GLSL Shaders, KTX2 / Basis Texture Compression, Draco Mesh Compression.
- **Frontend & Runtimes:** JavaScript (ES6+), HTML5 Canvas, CSS3, CSS3DRenderer, Web Audio API, GSAP Animations.
- **Build & Bundler:** Webpack 5, Babel, MiniCSSExtractPlugin, CopyWebpackPlugin.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v16+ recommended)
- [npm](https://www.npmjs.com/)

### Installation & Local Setup

```bash
# Clone the repository
git clone https://github.com/roshandhiman/roshandhiman--portfolio.git

# Navigate to project directory
cd roshandhiman--portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open `http://localhost:8080` in your browser to explore the 3D world!

### Production Build

```bash
# Create optimized production build
npm run build
```

The output bundle will be generated inside the `dist/` directory.
